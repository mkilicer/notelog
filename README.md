# notelog

**notelog lives at [github.com/mkilicer/getnotelog](https://github.com/mkilicer/getnotelog).**

Memory for your AI: a local MCP server for Claude Code, Codex, Cursor and Claude Desktop that keeps your notes as
plain Markdown files.

```sh
npx -y getnotelog init --claude
```

- Source code and docs: [github.com/mkilicer/getnotelog](https://github.com/mkilicer/getnotelog)
- npm: [getnotelog](https://www.npmjs.com/package/getnotelog)
- Hosted version (web, phone, Claude & ChatGPT connectors): [getnotelog.com](https://getnotelog.com)
